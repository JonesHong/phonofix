# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | ✅ Active          |
| 0.3.x   | ⚠️ Critical only (3 個月 grace until v0.5.0) |
| < 0.3   | ❌ No support      |

## Reporting a Vulnerability

請透過 GitHub **Private Security Advisory** 回報（不要開公開 issue）：
1. 到 https://github.com/JonesHong/phonofix/security/advisories
2. 點 "Report a vulnerability"
3. 提供 reproducer + impact assessment

預期回應時間：72 hours 內初步確認，1-2 週 patch release。
